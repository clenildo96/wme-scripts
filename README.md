---

## 🚀 Como Instalar e Usar

1. Instale a extensão **Tampermonkey** no seu navegador (Chrome, Edge, Firefox, etc).
2. Volte na tabela acima e clique em **Instalar** no script que deseja.
3. Na nova aba que vai se abrir, confirme a instalação.
4. Acesse o [Waze Map Editor](https://www.waze.com/editor) e mande ver nas edições.
